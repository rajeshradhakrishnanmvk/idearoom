# Quickstart: ThinkPak Idea Studio

## Run Locally

1. Open `specs/002-thinkpak-idea-studio/app/index.html` in a browser.
2. Start in the Generate section and create at least 3 ideas.
3. Shape one idea in the Shape section.
4. Define criteria and score ideas in Evaluate.
5. Select a winner and review rationale.

## Manual Validation Checklist

- App loads with no network requests to third-party URLs.
- Create/edit/delete idea actions work.
- Data persists after browser refresh.
- Scoring updates ranking immediately.
- Winner rationale shows top strengths.

## Reset Data

Use the "Reset All Data" button in the UI or clear localStorage for the page origin.
