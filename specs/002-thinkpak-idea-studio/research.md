# Research: ThinkPak Idea Studio

## Objective
Create one concrete product idea using ThinkPak prompts, then evaluate alternatives before selecting the best concept.

## Ideation Inputs (Cards 3-47)

- Card 4 (Substitute): Replace sticky notes and whiteboards with a structured browser workspace.
- Card 8 (Combine): Combine ideation prompts with scoring tools in one flow.
- Card 13 (Adapt): Adapt brainstorming canvases into solo and team-friendly guided steps.
- Card 28 (Put To Other Uses): Reuse daily journaling entries as idea seeds.
- Card 34 (Eliminate): Remove account creation, backend setup, and external integrations.
- Card 38 (Rearrange): Reorder process to generate many ideas first, then evaluate.
- Card 43 (Reverse): Start from constraints first, then discover ideas that fit.

## Candidate Concepts

1. Prompt Roulette Board
- Random card spinner that produces quick prompts and captures idea snippets.

2. Idea Studio with Guided Pipeline
- Three-stage workflow: Generate -> Shape -> Evaluate.

3. Constraint-First Idea Finder
- User defines strict limits first (time, skill, budget), app proposes adapted prompts.

## Evaluation (Cards 48-55)

### Method A: Label It (Card 49)
- Prompt Roulette Board: Likely
- Idea Studio with Guided Pipeline: Excellent
- Constraint-First Idea Finder: 50/50

### Method B: PMI (Card 50)

Idea Studio with Guided Pipeline
- Plus: clear flow, beginner-friendly, measurable decisions.
- Minus: more UI complexity than spinner-only concept.
- Interesting: can support both solo sessions and team workshop mode.

### Method C: Eight Factors (Card 55)

Scored out of 100.

- Prompt Roulette Board: 68
- Idea Studio with Guided Pipeline: 87
- Constraint-First Idea Finder: 61

## Selected Concept

Idea Studio with Guided Pipeline was selected due to strongest clarity, implementation feasibility, and user value while staying fully zero-dependency.

## Product Idea Statement

A browser-only ThinkPak Idea Studio that helps users generate, refine, and evaluate ideas through a guided pipeline using SCAMPER-style prompts and transparent scoring.
